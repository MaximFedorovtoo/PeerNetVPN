Adaptation: country properties removed except ISO_A2_EH; all rings retained;
Antarctica omitted. Longitude/latitude projected with
x = 500 + longitude * (460/180) * (0.86 + 0.14*cos(latitude radians));
y = 254 - latitude*2.6. Coordinates quantized to 1/16 map unit.
Binary format (big-endian): ASCII PNM1; uint16 country count; each country:
2 ASCII ISO-A2 characters, uint16 ring count; each ring: uint16 point count,
then point count pairs of uint16 x16/y16 coordinates. 9,993 coordinate pairs.
Country codes are grouped at runtime using the app's existing PeerRegions.
Geographic shapes and boundaries provide visual context only. Counts reflect
reported regions; the map does not imply GPS locations or verified countries.
