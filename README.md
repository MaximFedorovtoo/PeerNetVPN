# Uzelio

**[Скачать приложение для Android](https://github.com/MaximFedorovtoo/Uzelio/releases/latest/download/Uzelio.apk)**

**[Скачать приложение для Windows](https://github.com/MaximFedorovtoo/Uzelio/releases/latest/download/Uzelio-Windows.exe)**

Сеть для обмена интернет-подключением между участниками. Находите доступные узлы на карте, выбирайте регион и подключайте нужные приложения.

## Как начать

1. Установите Uzelio на своё устройство.
2. Включите раздачу и дождитесь автоматического измерения скорости.
3. Откройте карту и выберите доступный узел.
4. Выберите приложения, которые будут использовать подключение участника. Остальные продолжат работать через обычную сеть.

## Правила сети

- Чтобы пользоваться подключением других участников, включите свою раздачу. Минимального объёма отдачи нет.
- К одному устройству могут подключаться не более трёх устройств. Скорость раздачи — без ограничения или с выбранным лимитом не ниже трети измеренной исходящей скорости.
