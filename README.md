Текущая версия исходников — **0.5.0**. APK для испытаний публикуется как
предварительная debug-сборка. Разработка, сборка и проверки выполняются локально;
GitHub используется для исходников, истории и скачивания сборок.

Android-приложение для зашифрованного обмена интернет-подключением между участниками.
Интерфейс включает состояние VPN, карту обнаруженных узлов, статистику и настройки.
Android 10 и новее, root не нужен.

## Правила

- Включённая и доступная раздача обязательна для получения чужого трафика.
  Наличие клиентов и минимальный объём отдачи не требуются.
- Максимум три одновременно подключённых устройства.
- Один общий ограничитель на всех клиентов: треть измеренной исходящей скорости.
- Нет кредитов, стартовых гигабайтов, кошельков и покупок.
- Учёт реальных переданных байтов; восемь локализаций: English, русский, 中文,
  日本語, français, italiano, español, español de México.

## Установка и первое подключение — 0.5.0

1. Скачать `PeerNet-0.5.0-debug.apk` из раздела Releases и установить на оба
   Android-устройства. При локальной сборке APK находится в `dist/` после
   выполнения `tools/package.ps1`.
2. Включить раздачу на обоих и дождаться автоматического замера скорости.
3. Открыть «Карта»: адрес каталога на Synology уже задан по умолчанию.
   При необходимости его можно изменить или очистить в настройках.
4. Выбрать регион и найденный узел. На принимающем телефоне выбрать приложения
   для подключения и разрешить системное VPN-подключение Android.
   Остальные приложения продолжают использовать обычную сеть.

Коды между телефонами передавать не нужно. Краткоживущие подписанные объявления
и зашифрованные параметры сопряжения передаются через каталог, затем телефоны
обмениваются ими напрямую. Страна и свободные места заявлены участником;
доступность соединения проверяется отдельно. Каталог не пересылает VPN-трафик.

[Служба на Synology](docs/synology-bootstrap.md),
[проверки версии 0.4](docs/automatic-discovery-verification.md).
Ручные приглашения и сопряжение сохранены в нижней части экрана узлов как резерв.

### Прежний публичный TCP-каталог и CGNAT


В **Настройках** включите публичную сеть на участвующих устройствах. У доступного
из интернета участника скопируйте публичный контакт и добавьте его как первого
участника на остальных телефонах. Каталог подписанных записей распространяется
между ними автоматически. Телефон за CGNAT открывает исходящее соединение
к доступному участнику, который пересылает сквозной зашифрованный трафик.
Публичный контакт не содержит секрет приватного приглашения.

Для прежнего TCP-каталога выделенный сервер проекта не нужен, но хотя бы один участник должен быть
достижим по IPv4/IPv6 или через проброшенный TCP-порт 39281. Два телефона
за недоступными NAT сами по себе этого не обеспечивают. Наличие глобального
IPv6 тоже требует проверки входящего доступа у оператора.

В 0.3 отдельно добавлено прямое сопряжение ICE/WebRTC с публичными STUN Google
и Cloudflare, без TURN-сервера. Оно не требует включать публичный каталог.
Приглашения подписаны, ответ связан с конкретным запросом; секрет канала
привязан к ключу второго телефона и отзывается при закрытии. Первоначальный
обмен кодами выполняет пользователь. Некоторые NAT всё равно требуют
ретранслятора. Отсутствие центрального сервера не делает протокол неблокируемым.
[Результаты аппаратных испытаний](docs/nat-traversal-verification.md).

Публичный режим раскрывает участникам адрес, ключ и приблизительную страну.
Каталог показывает обнаруженную часть сети; это не полный перечень устройств
во всём интернете. На одном устройстве общий предел трёх обслуживаемых
идентичностей включает клиентов выхода и участников ретрансляции.

## Честные границы этой сборки

- Прямое сопряжение пытается пройти CGNAT с помощью ICE. Если сети не позволяют
  прямой путь, нужен доступный участник-посредник.
  Без первого живого контакта автоматический вход в сеть невозможен.
- Ограничитель использует автоматически измеренную оценку канала, а не скорость
  тарифа и не мгновенную доступную полосу. Измеряется отдача по пути к сервису
  проверки; она может отличаться от многопоточного теста другого провайдера.
  Скорость в интерфейсе указана в Мбит/с, объём трафика — в байтах.
- При включении, смене сети и каждые 15 минут отправляются до 24 МиБ тестовых
  данных через Selectel, с резервным провайдером 59telecom. Повторный замер разрывает текущие
  сессии, подключиться после него нужно снова. Если сервис недоступен, раздача
  интернет-трафика блокируется до успешного измерения.
- `https://api.country.is/` получает IP для определения страны. Ошибка
  геолокации не блокирует сеть, отображается неизвестная страна. Страну удалённого
  узла сообщает его приложение; это не доказательство его физического положения.
- TCP и UDP поддерживаются; IP multicast, ICMP и доступ клиентов к частным
  адресам владельца выхода запрещены/не маршрутизируются. DNS идёт через узел.
- Шифрование защищает участок между устройствами. Выходной узел видит
  назначения и незашифрованный прикладной трафик; приложение не обещает анонимность.
- Проверка обратной доступности раздачи не защищает от всех модифицированных
  клиентов. Для открытой недоверенной сети нужен дополнительный аудит протокола.
- На Android одновременно работает один системный VPN в профиле. Приложение
  использует foreground-уведомление и удерживает CPU во время раздачи.
- VPN маршрутизирует только явно выбранные приложения с запуском из меню.
  Остальные используют обычную сеть. Пустой список блокирует VPN; изменение
  выбора отключает текущий туннель до повторного подключения.
  Список показывает значки и названия приложений; выбор переключается
  нажатием по всей строке, а «Отмена» не меняет сохранённые настройки.

## Сборка на Windows

```powershell
powershell -ExecutionPolicy Bypass -File tools/build.ps1 :core:test :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

Скрипт использует portable Java 17, Gradle 8.13 и SDK 35 в `.tools`.
Если инструментов нет, скачивает их с официальных источников, сверяет
контрольные суммы и принимает лицензии SDK для локальной сборки.
Глобальные настройки не меняет. Из-за ограничений Java 17 на Windows при
кириллическом пути создаёт junction `C:\Users\Public\uzel-build-workspace`
к этой папке и временный каталог `C:\Users\Public\uzel-build-temp`.
Исходная папка не переносится.

Результаты: `app/build/outputs/apk/debug/app-debug.apk`,
`core/build/reports/tests/test/index.html`,
`app/build/reports/lint-results-debug.html`.

Для проверки на подключённом устройстве с разрешённой USB-отладкой:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build.ps1 :app:connectedDebugAndroidTest
```

## Структура

- `core/` — TLS, допуск устройств, общий ограничитель, TCP/UDP и SOCKS5-мост.
- `app/` — AndroidKeyStore, VPN, реальное измерение, DNS-SD и интерфейс.
- `docs/design.md`, `docs/protocol.md` — решения и границы протокола.
- `docs/verification-0.2.md` — актуальные проверки и ограничения; `verification.md` — история 0.1.
- `docs/device-routing-verification.md` — проверка настоящего VPN на двух телефонах через диагностический USB-мост; автономное межсетевое соединение пока не установлено.
- `THIRD_PARTY_NOTICES.txt` — лицензии нативного движка.
