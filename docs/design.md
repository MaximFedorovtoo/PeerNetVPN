# PeerNetVPN: Android DPN

## Согласованные требования

Android-приложение по макету «PeerNetVPN». Каждый участник предоставляет свой выход
в интернет и может выбрать чужой из списка. Получение разрешено, пока собственная
раздача включена и доступна; фактическое наличие клиентов не обязательно.
Нет стартового кредита, минимального объёма и расходуемого баланса.
Не более трёх одновременно обслуживаемых устройств. Общая скорость раздачи
ограничивается третью автоматически измеренной исходящей пропускной способности.
Страна узла определяется по его выходному IP. Интерфейс: en, ru, zh, ja, fr,
it, es, es-MX. Трафик считается автоматически, показатели — статистические.

## Реализация

Java 17, Android 10+, нативный интерфейс, foreground VPN service.
Официальный hev-socks5-tunnel 2.18.0 преобразует TUN в локальный SOCKS5.
Локальный SOCKS5 передаёт TCP и UDP по взаимно аутентифицированным TLS-соединениям
на Android-узел, который открывает обычные интернет-сокеты без root.
Ключ устройства хранится в AndroidKeyStore. Приглашение содержит адрес, отпечаток
сертификата и случайный секрет доступа. Сервер требует клиентский сертификат
и секрет; клиент проверяет закреплённый отпечаток. Лимит устройств считается
по сертификатам, а не по числу TCP-соединений.

При входе сервер проверяет обратную доступность раздачи клиента, затем поддерживает
контрольную сессию. Закрытие раздачи закрывает VPN и сессии клиентов.
Управляющая сессия имеет тайм-аут; потерянные клиенты освобождают места.
Один ограничитель на весь узел обслуживает оба направления исходящих передач:
к интернет-серверам и клиентам. Замер скорости идёт отдельно, без записи в
пользовательскую статистику; без действительного замера выход запрещён.
Android измеряет исходящий интернет через HTTPS POST Selectel, с резервным
провайдером 59telecom: две пробы по 1 МиБ в нормальном режиме, общий бюджет
до 3 МиБ включая неудачные попытки, меньшая скорость с запасом 20%.
Это предотвращает подмену интернет-скорости высокой скоростью локального Wi-Fi.
Измеряется доступная скорость конкретного интернет-пути, а не скорость тарифа.
Замер запускается автоматически при включении, смене сети, через 15 минут
и вручную. Повторный замер прерывает VPN и клиентские сессии до получения
нового лимита. При ошибке нет неограниченного режима.

## Поиск и география

Первый контакт: приглашение, локальный поиск DNS-SD. Чужие объявления не являются
основанием доверять ключу: нужна ссылка-приглашение. Список проверяет доступность
и число клиентов. Прямые интернет-соединения требуют доступного IPv4/IPv6
или проброса порта. Публичный режим добавляет подписанный каталог и relay
участников: устройства за CGNAT открывают исходящие соединения к доступному
участнику, который передаёт зашифрованные данные. Первый живой контакт
нужен для входа; централизованного каталога или relay проекта нет.
Выделенный сервер проекта не требуется.

HTTPS api.country.is используется только для оценки страны и публичного IP
устройства, не для передачи пользовательского трафика. При недоступности —
неизвестная страна; язык/локаль не подменяют геолокацию.
Selectel или 59telecom получает тестовые байты и IP во время измерения. Ни один из этих
диагностических сервисов не маршрутизирует трафик VPN. Таким образом, нет
выделенного сервера проекта, но эта сборка имеет внешние диагностические зависимости.

## Безопасность и приёмка

Выход запрещает адреса loopback, link-local, частные сети и multicast:
чужой клиент не должен получить доступ к локальным устройствам владельца узла.
Приглашение конфиденциально. Проверка доступности раздачи не доказывает честность
модифицированного клиента; нет заявления о защите от всех Sybil-атак.
Перезапуск/смена сети сбрасывает соединения и измерение. Состояния интерфейса
основаны на сетевых результатах, демонстрационных узлов нет.

Проверки: три устройства/отказ четвёртому, общий rate limit,
отказ без раздачи, неверный секрет и сертификат, TCP и UDP через TLS,
освобождение места, закрытие существующих соединений, блокировка частных
назначений, разбор приглашений, сборка APK и lint, проверка локализаций.
Полноценную мобильную приёмку отдельно проводить на двух физических Android
устройствах в Wi-Fi и разных сетях; не выдавать JVM-тесты за такую проверку.
