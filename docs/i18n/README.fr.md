# PeerNet pour Android

**[Télécharger l’application Android](https://github.com/MaximFedorovtoo/PeerNetVPN/releases/latest/download/PeerNet.apk)**

Un réseau pour partager une connexion Internet entre participants. Trouvez les nœuds disponibles sur la carte, choisissez une région et connectez les applications de votre choix.

## Premiers pas

1. Installez PeerNet sur votre téléphone.
2. Activez le partage et attendez la mesure automatique du débit.
3. Ouvrez la carte et choisissez un nœud disponible.
4. Sélectionnez les applications qui utiliseront la connexion du participant. Les autres continueront à utiliser votre réseau habituel.

## Règles du réseau

- Activez votre partage pour utiliser les connexions des autres participants. Aucun volume minimal de données envoyées n’est requis.
- Chaque appareil accepte jusqu’à trois appareils. Leur débit total est limité au tiers du débit montant mesuré.
