# Android 版 PeerNet

**[下载 Android 应用](https://github.com/MaximFedorovtoo/PeerNetVPN/releases/latest/download/PeerNet.apk)**

与其他参与者共享互联网连接。在地图上查找可用节点，选择地区，并为所选应用建立连接。

## 开始使用

1. 在手机上安装 PeerNet。
2. 开启共享，等待自动测速完成。
3. 打开地图，选择可用节点。
4. 选择使用参与者连接的应用。其他应用继续使用原来的网络。

## 网络规则

- 使用其他参与者的连接前，需要开启自己的共享。没有最低上传流量要求。
- 每台设备最多接受三台设备连接。共享的总速度不超过实测上传速度的三分之一。

支持 Android 10 及以上版本。提供八种界面语言。
