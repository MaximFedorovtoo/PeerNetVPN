# Uzelio

**[Android アプリをダウンロード](https://github.com/MaximFedorovtoo/Uzelio/releases/latest/download/Uzelio.apk)**

**[Windows 版をダウンロード](https://github.com/MaximFedorovtoo/Uzelio/releases/latest/download/Uzelio-Windows.exe)**

参加者同士でインターネット接続を共有するネットワーク。地図で利用可能なノードを探し、地域と接続するアプリを選べます。

## 使い方

1. スマートフォンに Uzelio をインストールします。
2. 共有を有効にし、自動速度測定が完了するまで待ちます。
3. 地図を開き、利用可能なノードを選びます。
4. 参加者の接続を使うアプリを選びます。他のアプリは通常のネットワークを使い続けます。

## ネットワークのルール

- 他の参加者の接続を使うには、自分の共有を有効にします。最低アップロード量の条件はありません。
- 1 台の端末に接続できるのは最大 3 台です。共有速度は無制限、または測定したアップロード速度の 3 分の 1 以上の上限を選べます。

Android 10 以降に対応。表示言語は 8 言語です。
