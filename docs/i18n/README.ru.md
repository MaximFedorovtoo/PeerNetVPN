# PeerNetVPN (PeerNet) для Android

Зашифрованный обмен интернет-подключением между Android-устройствами.
Требуется Android 10 или новее; root не нужен. В интерфейсе восемь языков.

**0.5.0 — экспериментальная debug-сборка.**

## Установка и подключение

1. Скачайте debug APK 0.5.0 из [GitHub Releases](https://github.com/MaximFedorovtoo/PeerNetVPN/releases) этого репозитория.
2. Установите его на оба устройства, разрешив установку из выбранного источника.
3. Включите раздачу на обоих устройствах и дождитесь замера исходящей скорости.
4. Откройте «Карта», выберите регион и доступный узел. Каталог обнаружения уже
   настроен; его адрес можно изменить в настройках.
5. На принимающем устройстве выберите приложения и разрешите VPN Android.
   Туннель используют только выбранные приложения. После изменения выбора
   подключитесь заново.

Для получения чужого трафика раздача должна оставаться включённой и доступной.
Наличие клиентов и минимальный объём отдачи не требуются. Один узел обслуживает
до трёх устройств; их общий предел — треть измеренной исходящей скорости.
Кредитов, кошельков и покупок нет.

## Ограничения и приватность

- Обнаружение не гарантирует соединение. Некоторые сочетания NAT/CGNAT требуют
  доступного участника-посредника; ручное сопряжение ICE/WebRTC работает без TURN.
- Каталог передаёт данные обнаружения и сопряжения, а не VPN-трафик. Ручные
  приглашения и сопряжение доступны как резерв. Приглашения храните в тайне.
- Шифрование защищает передачу между устройствами. Выходной узел видит назначения
  и незашифрованный прикладной трафик. PeerNet не обещает анонимность.
- Замер отправляет до 24 МиБ тестовых данных за цикл через Selectel или резервный
  сервис 59telecom: при включении раздачи, смене сети и каждые 15 минут.
  Замер разрывает сессии; подключитесь заново. Для раздачи интернет-трафика
  требуется успешный замер.
- Страна определяется через api.country.is. Заявленная страна узла приблизительна
  и не доказывает его местоположение. Публичный режим раскрывает адрес и ключ.
- В профиле Android работает один системный VPN. Раздача показывает постоянное
  уведомление и удерживает CPU. Поддерживаются TCP/UDP; ICMP, multicast и доступ
  к частной сети владельца выхода не маршрутизируются. DNS идёт через выход.

## Локальная сборка на Windows

Из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build.ps1 :core:test :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

Скрипт подготовит Java 17, Gradle 8.13 и Android SDK 35 в `.tools`, проверит
загрузки и примет лицензии SDK. APK: `app/build/outputs/apk/debug/app-debug.apk`.
Для аппаратных проверок нужно подключённое устройство с USB-отладкой.
См. [основной README](../../README.md), [протокол](../protocol.md) и
[уведомления о сторонних компонентах](../../THIRD_PARTY_NOTICES.txt).
