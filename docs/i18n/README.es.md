# Uzelio

**[Descargar la aplicación para Android](https://github.com/MaximFedorovtoo/Uzelio/releases/latest/download/Uzelio.apk)**

**[Descargar para Windows](https://github.com/MaximFedorovtoo/Uzelio/releases/latest/download/Uzelio-Windows.exe)**

Una red para compartir conexiones a Internet entre participantes. Encuentra nodos disponibles en el mapa, elige una región y conecta las aplicaciones que quieras.

## Primeros pasos

1. Instala Uzelio en tu teléfono.
2. Activa el uso compartido y espera a que termine la medición automática de velocidad.
3. Abre el mapa y elige un nodo disponible.
4. Selecciona las aplicaciones que usarán la conexión del participante. Las demás seguirán usando tu red habitual.

## Reglas de la red

- Activa tu conexión compartida para usar las de otros participantes. No se exige un volumen mínimo de datos enviados.
- Cada dispositivo acepta hasta tres dispositivos. Elige compartir sin límite o fijar un límite de velocidad de al menos un tercio de la velocidad de subida medida.
