# Проверка сборки 0.1.0 — 20 октября 2026

## Выполнено

Команда:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build.ps1 :core:test :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

- Gradle: `BUILD SUCCESSFUL`. Собраны приложение и instrumentation APK.
- JVM: 17 тестов, 0 ошибок. Реальные loopback TLS/TCP/UDP-сокеты,
  не имитация транспортного обмена.
- Допуск трёх сертификатов, отказ четвёртому и освобождение места.
- Отказ при выключенной раздаче, неверном секрете и несовпадающем TLS-ключе.
- Проверка общего ограничения скорости при двух одновременных потоках.
- Отказ при неизмеренной скорости; отзыв измерения закрывает существующие потоки.
- Запрет частных/служебных интернет-назначений.
- SOCKS5-аутентификация, TCP/UDP, фиксация источника UDP, отказ фрагментам,
  очистка соединений при закрытии.
- Android lint: 0 ошибок, 1 предупреждение `WakelockTimeout`. WakeLock
  намеренно живёт вместе с пользовательским foreground-сервисом и освобождается
  в `onDestroy`; отдельного тайм-аута сейчас нет.
- Проверено совпадение 77 ключей в восьми локализациях и корректность XML.
- `apksigner verify --verbose`: подпись APK действительна (v2, один подписант).
- `zipalign -c -P 16 4`: успешная проверка выравнивания APK.
- Диагностический POST 1 КиБ на Cloudflare из среды разработки получил HTTP 200.
  Это проверка доступности API здесь, не тест Android-канала.
- Независимая проверка критичного кода выявила гонки допуска потоков,
  перезапуска после выключения и устаревших callback. Исправления проверены
  повторным чтением; проверка периодического callback также помещена под монитор.

Тест для отзыва измерения сначала воспроизвёл ошибку (существующий поток
не закрывался, timeout), затем прошёл после исправления. Первые пять тестов
политик также запускались на незавершённой реализации и воспроизводили отказы.
Транспортные тесты сначала не компилировались из-за отсутствующего транспорта,
затем прошли на реализации; это не следует выдавать за полный assertion-first TDD.

## Не выполнено

`adb devices` не обнаружил подключённых устройств. Поэтому не запускались:

- UiSmokeTest и системное разрешение VPN на телефоне;
- native hev + TUN на реальном Android;
- два физических устройства, DNS, IPv6, браузер, фон и блокировка экрана;
- переключение Wi-Fi/мобильной сети, входящий звонок и ограничения производителя;
- отдельный нагрузочный прогон на Android и влияние на батарею.

Наличие APK, lint и JVM-тестов не заменяет эти проверки. Сборка предназначена
для испытаний, не объявляется проверенным публичным DPN-продуктом.

## Мобильная приёмка

1. Два устройства Android 10+ в одной Wi-Fi-сети без client isolation.
2. Разрешить уведомления, включить раздачу на обоих, дождаться замера.
3. Импортировать приглашение, подключить VPN, проверить сайт определения IP:
   при разных внешних сетях виден IP выбранного узла.
4. Проверить DNS, HTTP/HTTPS, UDP; недоступность частных адресов выхода.
5. Проверить три одновременных клиента и отказ четвёртому.
6. На клиенте выключить раздачу: получение прекращается. На сервере выключить
   раздачу: клиенты теряют соединения.
7. Сменить сеть: старые сессии закрываются; измерение сбрасывается и повторяется.
8. Измерить суммарную отдачу на всех клиентах относительно показанного лимита.
9. Проверить языки на небольшом экране и увеличенном системном шрифте.
