# PeerNetVPN 0.2: публичная сеть участников

Согласованная задача: список доступных узлов между сетями, соединения через
CGNAT без выделенного сервера проекта, замер скорости доступным в России
ресурсом, выбор приложений для VPN. Разработка и проверки только локальные.

## Решения

- Публичное участие включается пользователем отдельно. Приватные секреты
  приглашений не публикуются. Записи каталога подписаны ключом узла,
  ограничены по сроку действия и количеству; страна заявлена самим узлом.
- Каталог распространяется между известными участниками. Для первого входа
  нужен живой контакт. Это обнаруженная часть сети, не обещание полного
  перечня всех устройств в мире.
- Участник с доступным адресом может ретранслировать зашифрованные соединения
  других участников. Нужен как минимум один достижимый участник; если все
  адреса недоступны снаружи, гарантировать связь без посредника невозможно.
- Сквозное TLS-подключение проверяет ключ конечного узла. Один переход relay;
  ограничены очередь, время ожидания и число потоков. Совместный предел трёх
  устройств и общий ограничитель исходящего трафика действуют и на relay.
- VPN использует только явно выбранные установленные приложения. Пустой
  список запрещает запуск VPN. Изменение списка завершает текущий VPN.
- Новый источник замера проверяется отдельно с компьютера и двух телефонов.
  Успешный HTTP-код сам по себе не доказывает приём измерительных данных.

## Приёмка

1. Модульные тесты маршрутов, подписей, устаревания записей и ограничений.
2. TLS-тесты реальной пересылки через участника, отказов и отзыва доступа.
3. Независимая проверка критических сетевых изменений.
4. Локальная сборка APK, lint и тесты на подключённых Android-устройствах.
5. Проверка провайдера измерений из мобильной и Wi-Fi-сетей.
6. Отдельно указать результат межсетевого подключения: локальный relay-тест
   не считать доказательством прохождения операторского CGNAT.

## Исходные наблюдения

Подключены два телефона. На мобильном есть CGNAT IPv4 и глобальный IPv6;
на Wi-Fi — частный IPv4 и локальный IPv6. Доступность входящего IPv6
ещё не подтверждена. Другой VPN на мобильном устройстве не отключается.
