# Автоматическое обнаружение и стартовый сервер

## Согласованный результат

Пользователь разрешил временный сервер для первого подключения, последующий
обмен узлами между телефонами, соединение без кодов и список по регионам.
Сборки и испытания локальные. Стартовая точка развёрнута на Synology DS223j пользователя через отдельный HTTPS reverse proxy; внешний туннель не создавался.

## Архитектура

Краткоживущие подписанные объявления связывают существующую TLS-личность,
страну, состояние раздачи и отдельный временный ключ шифрования сигнализации.
Offer/answer шифруются для выбранного получателя; bootstrap хранит только
объявления и зашифрованные конверты с ограниченным временем жизни.
Один ограниченный бинарный обмен работает через HTTPS bootstrap и через
аутентифицированный mTLS уже подключённых участников. Дедупликация и TTL
предотвращают бесконечную пересылку. Сохраняются только публичные контакты;
секреты приглашений и SDP не записываются на диск.

Статус объявления «в сети» не доказывает доступность прямого VPN. Подключение
подтверждается ICE, mTLS и обратной проверкой собственной раздачи. Максимум
три участника и общий лимит upload/3 сохраняются. При полном исчезновении
достижимых контактов новый вход снова требует стартовой точки.

Регионы и страны показывают найденную часть сети. Просроченные объявления
удаляются; страна является заявлением узла, а не доказательством географии.

## Последовательность и владение

- [x] Core: подписанные объявления, шифрованные конверты, ограниченный store,
  mTLS-операция обмена; тесты подмены, replay, TTL, лимитов и отключения.
- [x] Android: автоматический обмен offer/answer для выбранного узла,
  фоновый HTTPS/peer обмен через физическую сеть, отмена при смене поколения.
- [x] Bootstrap: ограниченный HTTP endpoint за HTTPS, без дискового хранения
  сообщений; возможность расположить тот же endpoint на участнике.
- [x] UI: регионы, страны, состояние объявления и реальные свободные места,
  подключение одной кнопкой, ручные коды остаются резервным способом.
- [x] Независимая проверка криптографии и жизненного цикла; локальная сборка.
- [x] Два физических телефона: первый вход без передачи кодов по ADB,
  VPN выбранного приложения и прямой выход исключённого, сохранение рабочего
  канала после остановки bootstrap; отчёт о границах повторного входа.

## Приёмка и ограничения

Без работающего публичного адреса нельзя заявлять аппаратную приёмку
bootstrap. Не покупать сервер, не создавать учётные записи и не открывать
другие локальные сервисы. Результаты с тремя участниками нельзя выводить из
испытания двух телефонов: распространение третьему проверяется отдельно.
Суммарные токены агентов и стоимость: нет данных. Время до принятия задачи:
фиксируется после фактической приёмки, не оценивается заранее.

Результаты проверки физического отключения USB и границы HTTP-подтверждения: см. ../../automatic-discovery-verification.md.
