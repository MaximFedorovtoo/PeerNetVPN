# Публикация PeerNetVPN 0.5.0

Дата подготовки: 21 октября 2026 года.
Репозиторий: https://github.com/MaximFedorovtoo/PeerNetVPN

## Состав

- Исходники Android-приложения, ядра, диагностических приложений и каталога.
- Java, Gradle/Groovy, PowerShell, XML, YAML, HTML и документация Markdown.
- Краткие руководства на всех восьми языках интерфейса в `docs/i18n/`.
- APK 0.5.0 (versionCode 5), архив исходников и SHA-256 в GitHub Releases.
- Лицензионные уведомления зависимостей в `THIRD_PARTY_NOTICES.txt`.

Зависимости, SDK/JDK, локальные ключи, кеши и результаты сборки не входят
в историю Git. Автоматизации GitHub Actions не создаются.

## Локальные проверки

```powershell
& tools/build.ps1 :core:test :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
& tools/verify-search-ui.ps1
& tools/verify-discovery-refresh.ps1
& tools/package.ps1
```

При подготовке публикации: 100 тестов ядра, 11 тестов поиска/интерфейса,
10 тестов обновления каталога — без ошибок. Сборка и Android Lint успешны.
Gradle использовал актуальные кешированные результаты неизменённых задач.
Аппаратные испытания в этой задаче повторно не выполнялись.

Это экспериментальная debug-сборка, подписанная отладочным ключом,
не выпуск для магазина приложений. Ограничения NAT, проверки раздачи
и приватности перечислены в README. Выбор лицензии исходного проекта
остаётся за владельцем; лицензии зависимостей не заменяют её.

## Учёт работы

Тип задачи: подготовка репозитория, локализация документации и публикация.
Исполнители: координатор и один помощник по восьми переводам.
Доработки помощника: один проход для окончательных формулировок публикации.
Суммарные токены, денежная стоимость и время до принятого пользователем
результата: нет данных. Сопоставимого одноагентного замера нет;
вывод об экономии не делается.
