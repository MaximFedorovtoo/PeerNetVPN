Completeness limitation:
  The AAR itself has no LICENSE, NOTICE or PATENTS entries. Publisher release
  assets contain AARs, without a build-generated license manifest. Although the
  publisher collection is present at the pinned 2026 tag, GitHub file history
  identifies its last modification as f0252bec67ad90432a77dce9af8041e3717c57ed,
  2021-09-08. It is stale relative to M144 and must not be described as an audited
  exhaustive notice set for this binary. Relevant modern dependency license
  revisions and the exact native linked target graph are not fully established.
  The upstream pinned tools_webrtc/android/build_aar.py generates LICENSE.md
  NEXT TO the AAR through tools_webrtc/libs/generate_licenses.py, using GN desc
  on the actual build output/targets. Obtaining that exact generated LICENSE.md
  and GN dependency/build provenance from the publisher is the remaining task
  for an exhaustive binary distribution notice audit. No legal-completeness
  or verified-source-build claim is made by this collection.
