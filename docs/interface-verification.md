# PeerNet 0.5 интерфейс и брендбук

Проверено 21 октября 2026 года. Визуальная концепция закреплена в
`brandbook.html` и в правилах AGENTS.md для следующих изменений интерфейса.

## Изменения

- Тёмная тема, объёмные градиентные карточки, кнопки с откликом на нажатие.
- Схематичная карта с количеством свежих обнаруженных узлов по регионам.
  Устаревшие объявления не учитываются; неизвестная страна остаётся в фильтре
  «Регион неизвестен», без вымышленного положения на карте.
- Различаются подготовка, поиск, отсутствие узлов, недоступность каталога,
  необходимость включить раздачу и ожидание дольше 30 секунд.
- Повторный поиск отслеживает завершение именно запрошенного обновления.
- Ручное сопряжение, адрес каталога и пояснения перенесены в «Подробнее».
- Выбор приложений содержит значки и поиск; выбор сохраняется при фильтрации.
- Добавлены короткие подписи на восьми языках.

## Проверки

- Android APK, instrumentation APK и lint: BUILD SUCCESSFUL; lint 0 errors,
  12 warnings (не утверждается отсутствие предупреждений).
- `tools/verify-search-ui.ps1`: 11 тестов пройдены, включая пустой результат,
  ошибку каталога, ограниченное ожидание и сохранённое место сопряжённого узла.
  Регрессия занятого узла сначала воспроизведена падающим тестом.
- `tools/verify-discovery-refresh.ps1`: 10 тестов пройдены.
- На OnePlus и Xiaomi установлен versionCode 5, versionName 0.5.0.
- InterfaceDeviceTest на каждом телефоне: OK (1 test), отображение четырёх
  экранов. Рендер выполнялся внутри приложения с принудительной раскладкой
  при заблокированном дисплее; это не снимок физического экрана телефона.
- Визуально проверены полученные рендеры главного экрана и карты; финальные
  рендеры карты сохранены локально в `.tools/ui-device/*-map-final.png`.
- Независимая проверка кода: две ошибки исправлены, повторная проверка
  не обнаружила оставшихся конкретных блокирующих замечаний.
- Тестовый пакет удалён с обоих телефонов. Пользовательские настройки
  каталога и выбора приложений сохранены; тест раздачу не запускал.

## Границы

Карта показывает обнаруженную часть сети по заявленным странам, а не точные
адреса людей и не весь мировой пул. Это нативная схема континентов, не
растровая иллюстрация из концепт-макета. Живое соединение двух телефонов и
полное испытание всех локалей с крупным системным шрифтом в этом обновлении
повторно не проверялись. Брендбук автономный, без внешних ресурсов; его
визуальный просмотр в браузере не выполнен из-за запрета локального URL.

Суммарные токены и стоимость работы агентов: нет данных. Вывод об экономии
по этому выполнению не делается.
