  Один запуск каждой версии показывает разницу около 1.1%, не доказывает
  статистически значимого изменения производительности.

## Synology

контейнер `peernet-discovery`, существующий RustDesk не изменялся.
Подготовлен официальный JRE 17 ARM64; наружу доступен только каталог через
HTTPS reverse proxy, внутренний порт контейнера привязан к loopback NAS.
Установка показала отсутствие поддержки CFS CPU quota и PID limit ядром NAS.
CPU quota удалена; PID limit Docker игнорирует. Память 192 MiB подтверждена DSM.

## Испытания телефонов

На двух телефонах установлена версия 0.4.0 с названием PeerNet.
В первой попытке оба нашли друг друга через HTTPS без передачи кодов, но
раздача на мобильном телефоне выключилась приблизительно через 20 секунд.
Причина выключения не установлена; OnePlus не подключился, клиентский тест
зафиксировал failure. Успешную приёмку из этой попытки выводить нельзя.
Во второй попытке телефоны нашли друг друга через Synology без передачи кодов
или SDP по ADB. OnePlus установил настоящий VPN, мобильный телефон — раздачу;
оба показали CONNECTED и один достижимый сопряжённый узел.

Выбранное тестовое приложение: HTTP 200, vpnTransport=true, внешний адрес
31.173.87.114 (мобильная сеть). Исключённое приложение: HTTP 200,
vpnTransport=false, адрес 79.104.26.213 (Wi-Fi). Проверялись обычные HTTPS-запросы
без принудительной привязки сокета к сети.

После остановки контейнера Synology и очистки URL каталога на обоих телефонах
соединение и свежие объявления сохранялись минимум 132 секунды при TTL 120 с.
Три пары повторных запросов выбранного/исключённого приложения дали HTTP 200
и те же разные внешние адреса. Списки adb forward/reverse были пусты.

Физическое отключение обоих USB наблюдалось в 14:10:06 МСК. После повторного
подключения получены полные журналы обоих 15-минутных тестов: оба OK (1 test),
длительность 902.11 и 906.988 секунды. После отключения URL каталога все 363
снимка OnePlus показывают ONLINE/CONNECTED, vpn=true, announced=1, reachable=1;
все 368 снимков мобильного телефона — ONLINE/CONNECTED/SHARING и один узел.
Таким образом, сохранение соединения охватывает период физического отключения
USB. У снимков нет индивидуальных временных меток; вывод основан на непрерывном
двухсекундном цикле и полном интервале теста. Состояние CONNECTED само по себе
не доказывает успешность каждого HTTP-запроса.

Скрипт всех шести пар probe-запусков завершился, но подробные HTTP-результаты
последних запусков уже отсутствуют в logcat. HTTP-маршрутизация подтверждена
сохранёнными ранее запросами; отдельное подтверждение HTTP именно в период
физического отключения USB не заявляется. Полные локальные журналы:
.tools/auto2-oneplus-final.txt и .tools/auto2-mobile-final.txt; сохранённые HTTP:
.tools/auto2-routing-evidence.txt.

Контейнер снова запущен; публичный GET /health вернул 200, в том числе после
завершения работ. Финальная сборка 0.4.0 установлена на оба телефона. Отдельный
testConfigure на каждом дал OK (1 test), сохранив HTTPS-адрес Synology.
Тестовые APK удалены. Финализатор испытания остановил тестовую раздачу и
восстановил прежний выбор приложений; новая сессия запускается пользователем.
Суммарные токены агентов и стоимость: нет данных. Вывод об экономии не делался.
